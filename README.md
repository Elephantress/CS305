# CS305
Client Summary and Software Requirements

My client was Artemis Financial, a financial services company that needed to improve the security of its software application. The company wanted to address software security vulnerabilities and protect sensitive financial information from potential threats. The goal was to identify weaknesses in the existing application, implement secure coding practices, and improve the protection of data exchanged between the application and its users. This included using secure communication protocols and ensuring that the software followed appropriate security practices.
Identifying Vulnerabilities and the Importance of Secure Coding
One thing I did well was use vulnerability assessment tools to identify potential security weaknesses and review the application's dependencies. I also worked to understand the vulnerabilities and determine how they could affect the application. Coding securely is important because it helps prevent data breaches, unauthorized access, and other security incidents. Software security adds value to a company by protecting customer information, maintaining customer trust, reducing financial and legal risks, and supporting the company's reputation.
Challenges and Helpful Parts of the Vulnerability Assessment
One challenging part of the vulnerability assessment was understanding the reported vulnerabilities and determining which issues needed the most attention. Some vulnerabilities require more investigation to understand their severity and whether they affect the application. The assessment was helpful because it showed me how automated tools can identify potential weaknesses and why developers must review the results rather than rely only on automated reports. It also helped me understand the importance of addressing security issues early in the software development process.
Increasing Layers of Security
I increased layers of security by implementing secure communication using HTTPS and a self-signed certificate, as well as reviewing dependencies for known vulnerabilities. These measures helped improve the protection of data and the application's overall security. In future projects, I would use tools such as dependency vulnerability scanners, static application security testing (SAST), and dynamic application security testing (DAST) to assess risks. I would also consult vulnerability databases, such as the National Vulnerability Database (NVD), and use the severity and relevance of each finding to prioritize mitigation techniques.
Ensuring Functionality and Security
I made sure the application remained functional by running tests before and after making changes and comparing the results. After refactoring the code, I checked that the application continued to produce the expected output and that the security improvements did not introduce new problems. I also reviewed the dependency scan results to identify remaining vulnerabilities and verify that the changes addressed the intended issues. Testing, code reviews, and repeated vulnerability assessments are important because they help confirm that an application remains functional while becoming more secure.
Helpful Resources, Tools, and Coding Practices
The tools and practices I used included Java, secure coding principles, dependency vulnerability scanning, cryptographic hashing, HTTPS, and digital certificates. I also learned the value of reviewing software dependencies, documenting changes, testing regularly, and following established security guidelines. These skills will be useful in future programming projects because they help developers identify risks, protect data, and create software that is easier to maintain and more reliable.
Demonstrating My Skills to Employers
The Artemis Financial project is a useful example of my work because it demonstrates my ability to examine an existing application, identify potential security vulnerabilities, apply security improvements, and test the software after making changes. I can use this project in my portfolio to show employers that I understand the importance of secure software development and can apply security practices in a practical situation. It also demonstrates my ability to troubleshoot problems, evaluate risks, and balance software functionality with security requirements.
